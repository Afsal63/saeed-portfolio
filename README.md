# Muhammed Saeed TK - Performance Marketing Portfolio

A modern, high-converting portfolio website for **Muhammed Saeed TK**, Performance Marketing Specialist & Growth Strategist based in Dubai, UAE.

Built with **Next.js 16 (App Router)**, **TypeScript**, **Tailwind CSS v4**, and **Lucide Icons**.

---

## 🌟 Key Features

1. **Strategic Value Proposition**:
   - Positions Muhammed Saeed TK as the rare performance marketer who combines technical paid media execution (Meta Ads, Google Ads, server-side Meta CAPI) with the financial discipline of an **accounting background** (BBA, Tally, Zoho Books, cash-flow ledger reconciliation).

2. **Interactive Photo Showcase**:
   - Uses the transparent cutout photos provided:
     - **Full Stance** (`saeed-standing.png`): Hero standing cutout with ambient glow lighting.
     - **Growth Desk** (`saeed-workspace.png`): Laptop workstation cutout featured in Hero switcher and Accounting Advantage section.

   - **90 Leads in 24 Hours**: Rapid Meta ad sprint for travel agency client.
   - **816.2K Views (390% Growth)**: 3-month reach & impressions scaling for Thanima Food Industries.

   - **10,199 People Reached**: B2B enterprise software pipeline with server-side CAPI.

4. **Interactive Ad ROI & Lead Estimator**:
   - Dynamic calculator allowing visitors and hiring managers to select their target currency (AED, USD, INR), choose their industry vertical, and adjust monthly ad budgets to view projected qualified leads, CPL, impressions, and ROAS.

## 🚀 Getting Started

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
npm run build
npm run start
```
Runs the optimized production build with Turbopack and static prerendering.
